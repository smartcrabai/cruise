# Exact UI policy

Applies to apps built on the [Exact](https://github.com/expo/exact) runtime: Contract views (`app.contract`) with TypeScript data, launched through the app's `exact.mjs`. Apply the [common UI E2E policy](common.md). Exact is neither React Native nor an ordinary browser app, even on its web host: use Exact's own tooling for every host and do not substitute Playwright, Detox, or XCUITest runs for it.

- **Targets:** read the app's `AGENTS.md` and `app.json` before choosing hosts, then check each target host the app declares; a native-only app needs no web run. Run every command through the app's `bun exact.mjs …` launcher, which pins its source checkout; do not install another Exact CLI.
- **Persistent E2E:** author assertion-bearing tests in `*.test.contract` beside `app.contract`; the starter `app.test.contract` is a placeholder to replace. Run `bun exact.mjs verify <web|ios|android|windows>`: it builds, runs the tests, checks the first screen and each test's end (light, dark, two widths), reads the accessibility tree, and rereads screens at the largest text size. macOS and Linux have no `verify`: use `bun exact.mjs test macos`, and on Linux build with `bun exact.mjs linux` before `bun exact.mjs test linux`. Android and Linux `test`/`agent` do not build; build first and after each edit.
- **Visual interaction:** drive the actual app with `bun exact.mjs agent <host> …` and save captures with `"screenshot .exact/<name>.png"` (macOS: `--chrome platform` and `"screenshot … window"` for native chrome), then inspect the pixels. A screen that must be checked or captured is a test's end. To compare against a reference, use `"screenshot .exact/x.png compare ref/x.png"` and read its textual differences and diff image. On iOS use `agent ios` captures, not `xcrun simctl io booted screenshot`, which can capture another simulator.
- **Waiting:** wait on the app's own conditions (`clock settle`, `clock data`, `clock until state <path> == <literal> within <ms>`), not fixed sleeps or `clock +N real`.
- **Reports:** read the whole verification report; counted findings can accompany exit status zero. Fix app findings for at most three rounds, then report what remains without weakening tests.
- Native hosts need their toolchains: macOS with Xcode for iOS and macOS, the Android SDK, JDK, and the device `ANDROID_SERIAL` names for Android, Linux desktop libraries for Linux. Report a host whose toolchain, device, or simulator is unavailable as untested; never count a web run as native coverage. Keep scratch output in `.exact/`.
