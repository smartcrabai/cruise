# Fyne UI policy

Applies to Go apps whose UI is built with [Fyne](https://fyne.io/). Apply the [common UI E2E policy](common.md).

- **Fast interaction and visual loop:** Preserve suitable existing tooling first. Fyne's [`fyne.io/fyne/v2/test` package](https://docs.fyne.io/api/v2/test/pkg/) provides an in-memory test app/window and input helpers such as `Tap`, `TapCanvas`, `Drag`, and `Type`. Use them to exercise the app's actual UI objects and assert meaningful user-visible behavior. Capture the window canvas with [`fyne.Canvas.Capture()`](https://docs.fyne.io/api/v2/fyne/canvas/) and inspect its pixels. A bare `test.NewCanvas()` has no painter and captures a blank image; use a test window or a painter-backed canvas for image capture. Optional [`RenderToMarkup`](https://docs.fyne.io/api/v2/test/pkg/#func--rendertomarkup) or image assertions can add focused deterministic checks, but markup and goldens are not required and do not replace pixel inspection.
- **Persistent E2E:** Save deterministic assertion-bearing Go tests (`*_test.go`) that exercise real UI flows and meaningful success/failure or boundary behavior through production app paths. Use `test.NewTempApp(t)` and `test.NewTempWindow(t, content)` where suitable for test-scoped app/window cleanup; run the relevant module tests with `go test ./...`. Isolate app/window state, and do not run tests that mutate Fyne's current app, driver, theme, or other shared state in parallel. Do not add a custom CLI or require image goldens.
- **Runtime limits:** Fyne's test driver and software capture run without displaying a native window. They do not evidence native platform chrome, real OS input behavior, accessibility integration, or other OS integrations. For final visual and platform E2E, use the intended app runtime and suitable tooling already established in the repository. If it is unavailable, report the exact blocker and unverified scope; headless test results alone are not final runtime evidence.

See Fyne's [Testing Graphical Apps guide](https://docs.fyne.io/started/testing) and [`software.WindowlessCanvas` API](https://docs.fyne.io/api/v2/driver/software/windowlesscanvas/) for the official testing and software-rendering interfaces.
